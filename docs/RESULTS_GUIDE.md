# Results guide: interpretation and column dictionary

For the complete analysis process and the role of every module, start with [WORKFLOW_ROADMAP.md](WORKFLOW_ROADMAP.md).

This guide defines the current result tables module by module. The integrated interpretation report is generated by Module 8. It is not necessary to wait until Step 8 to understand a column.

## General reading rules

- Each subsection specifies **one row** (the unit represented by a table). Cell counts are not automatically independent replicate counts.
- NA means unavailable, inapplicable or not estimable as described; it never means an estimated zero.
- A retained branch is a candidate, not an EN-selected branch; a selected branch is not automatically a historical expression shift.
- All downstream coefficients/contrasts use the prepared expression scale. Upstream DEG avg_log2FC is a separate quantity. Neither scale is inferred solely from a layer name.
- Training fit, tuning CV, cell-subsampling stability and independent biological replication are different forms of evidence.
- Clone-balanced fitting and ordinary unweighted IID Gaussian IC refits use different weighting targets. Read IC as an exploratory working-model comparison.

## Modules 0–1: text reports

Module 0 prints package availability/loading and session Info, not expression results. Module 1 produces one text report: assay/layer names and dimensions, metadata names/types/missing counts, sample-related value counts, cell overlaps, clone counts, and optional sample counts. Module 1 metadata field names depend on the input object; they are not newly generated biological measurements. Standard stored Seurat fields include cell_id (canonical barcode), sample_id/orig.ident (stored sample labels), nCount_RNA (stored RNA count total), and nFeature_RNA (stored detected-feature count); they are not recalculated by inspection. Missing cell_type is not grounds to discard a clone-mapped cell here.

The printed Module 0 package table has `package` (R package name) and `installed` (whether requireNamespace could load it; FALSE can mean absent or unloadable). Its later load test is separate. The printed Module 1 metadata table has `column` (metadata field name), `type` (stored R class), and `missing` (number of NA entries over the full object, not the clone subset; blank strings are not counted by that field). Sample-value tables show labels and cell counts over the full object. Clone counts in the report use matched analysis cells instead.

## Module 2: tree preparation

Purpose: establish tree/cell/clone correspondence and reusable branch predictors. For this dataset, all four clones are monophyletic under the supplied root; five collapsed predictors span three independent directions. This does not establish root or branch confidence. Printed matrix rows are clones and columns are branch memberships: 1 means below the branch, 0 means outside. An all-zero clone row is a reference predictor pattern, not absent expression. The uncollapsed branch-size filters leave 109 canonical candidates; their within-clone topology is exploratory.

### module02.branches.tsv

**One row:** One saved-tree edge per tree mode, including excluded edges. Read mode/included/reason before using any branch.

| Column | Meaning and interpretation |
|---|---|
| `branch_id` | Identifier such as branch_edge_1351, tied to an edge of the saved Module 2 tree. It is not an expression value or an inferred historical event. |
| `edge_index` | One-based row of the edge matrix in the saved pruned/reordered tree. Do not apply it to a differently ordered tree. |
| `parent_node` | Saved-tree node at the upstream end of the edge. A node index is not an identified ancestral cell. |
| `child_node` | Saved-tree node at the downstream end of the edge; descendants define the binary predictor. |
| `child_label_raw` | Original internal-node label at the child, if present. Its support meaning and scale have not been validated; NA for unlabeled/terminal nodes. |
| `branch_length` | Input edge length, when present. The binary branch regression does not use this as an evolutionary distance or covariance. |
| `n_descendant_cells` | Number of retained tree cells below this edge. |
| `descendant_fraction` | n_descendant_cells divided by all retained tree cells. Used in the uncollapsed size filter. |
| `is_terminal_edge` | TRUE when the edge ends in one cellular tip. This is distinct from a terminal clone branch. |
| `complete_clones_only` | TRUE when every clone represented below the edge is present in its entirety; no clone is split. Required for collapsed predictors. |
| `descendant_clones` | Clone labels found below the edge, separated by semicolons. In an uncollapsed tree these can represent only some cells of a clone. |
| `splits_within_clone` | TRUE if at least one clone contributes cells below and outside the edge. This does not establish that the cellular subdivision is reliable. |
| `mode` | collapsed or uncollapsed design. These are separate candidate dictionaries even when an edge ID occurs in both. |
| `included` | TRUE means retained as a candidate predictor during tree preparation, NOT selected by Elastic Net. |
| `reason` | Why an edge was retained/excluded: retained, splits_clone, universal_partition, original_cellular_edge_filters, duplicate_partition, or complement_with_intercept. |
| `equivalent_to` | Canonical branch with duplicate/complementary membership, where recorded. NA means no such equivalence was assigned; general linear dependence can still exist. |
| `equivalent_sign` | +1 for identical membership; -1 for a complement. Complement recoding also changes the intercept; this is algebraic bookkeeping, not an effect estimate. |

### module02.clone_checks.tsv

**One row:** One retained clone and its structural monophyly check.

| Column | Meaning and interpretation |
|---|---|
| `clone_id` | Clone label, kept as an identifier even if it looks numeric. It is not a continuous predictor. |
| `n_cells` | Number of cells supporting this row, group, or analysis. Cells are not automatically independent biological replicates. |
| `mrca_node` | Index of the most recent common ancestor of a clone in the saved supplied-root tree; a singleton uses its tip index. |
| `n_cells_below_mrca` | All retained cells descended from that ancestor, including any cells of other clones. |
| `monophyletic` | TRUE when the clone cells exactly equal the cells below its MRCA under the supplied root. Structural agreement is not statistical branch support. |
| `mrca_label_raw` | Input node label at the MRCA, where present. Do not automatically call it a bootstrap probability. |


## Module 3: candidate selection and prepared expression

The original DEG filters and ranking are preserved. The reviewed dataset produced 9,612 candidates and 100 ready extracted genes. This ranking reuses prior clone DE evidence; it is not independent confirmation of phylogenetic localization.

## Module 4: collapsed cell-level pilot

The reviewed CLDN16 fit selected a negative Clone 3 and positive Clone 0 EN contribution. A linear basis coefficient can use a different reference than an inside-vs-rest contrast: do not compare them as interchangeable fold changes. The full clone model can fit training data better simply because it is unshrunk. In the reviewed example, the Clone 3 basis coefficient is about -2.522 relative to the saved basis baseline, its equal-clone-versus-rest contrast is -2.950, and its EN contribution is -2.399. They differ because their reference/parameterization and shrinkage differ, not because the tables disagree.

### module04.coefficients.tsv

**One row:** One model term (including intercept) from the collapsed pilot. EN and linear coefficients have different parameterizations.

| Column | Meaning and interpretation |
|---|---|
| `model` | Method name: elastic_net, linear, contrasts; fit metrics also include intercept_only and clone_means_reference baselines. |
| `term` | Regression term/branch ID, or a contrast identifier in resampling summaries. Interpret together with model and effect_type, not by ID alone. |
| `coefficient` | Fitted model coefficient in prepared response units. Penalized simultaneous contributions and unpenalized basis coefficients have different meanings. |
| `selected` | Elastic Net coefficient is exactly nonzero. NA for linear terms because no variable selection is performed. The intercept is not a branch, even if this flag is TRUE. |
| `interpretation` | Explicit description of what the estimate represents and its limitations. |
| `descendant_clones` | Clone labels found below the edge, separated by semicolons. In an uncollapsed tree these can represent only some cells of a clone. |

### module04.contrasts.tsv

**One row:** One eligible collapsed biological branch partition. Root complements are sign-reversed redundant descriptions.

| Column | Meaning and interpretation |
|---|---|
| `branch_id` | Identifier such as branch_edge_1351, tied to an edge of the saved Module 2 tree. It is not an expression value or an inferred historical event. |
| `contrast` | Human-readable definition of the comparison; inside minus outside is the sign convention. |
| `descendant_clones` | Clone labels found below the edge, separated by semicolons. In an uncollapsed tree these can represent only some cells of a clone. |
| `comparison_clones` | Clone labels outside the collapsed partition. |
| `inside_equal_clone_mean` | Mean of the individual clone means inside a collapsed partition. Each clone receives equal weight, not each cell. |
| `outside_equal_clone_mean` | Mean of the individual clone means outside a collapsed partition, again equally weighting clones. |
| `difference` | Inside mean minus comparison mean, on the prepared response scale. Collapsed contrasts weight clone means equally; uncollapsed contrasts compare cells of one clone. |
| `clone_weights` | Explicit signed weights on clone means for a collapsed contrast; positive weights sum to 1 and negative weights to -1. |
| `equivalent_to` | Canonical branch with duplicate/complementary membership, where recorded. NA means no such equivalence was assigned; general linear dependence can still exist. |
| `interpretation` | Explicit description of what the estimate represents and its limitations. |

### module04.fit_metrics.tsv

**One row:** One method or baseline evaluated on its fitting cells.

| Column | Meaning and interpretation |
|---|---|
| `model` | Method name: elastic_net, linear, contrasts; fit metrics also include intercept_only and clone_means_reference baselines. |
| `n_cells` | Number of cells supporting this row, group, or analysis. Cells are not automatically independent biological replicates. |
| `n_clones` | Number of clone labels contributing to this fit; not number of independent patients. |
| `weighted_rmse` | sqrt(sum(weight × residual²)/sum(weight)); balances clone contributions. |
| `weighted_mae` | sum(weight × abs(residual))/sum(weight). |
| `weighted_r_squared_apparent` | 1 − weighted residual sum of squares / weighted total sum of squares about the balanced mean. Training fit, not external explained variance. |

## Module 5: stability and working information criteria

Module 5 names the shared validation step/script. Its collapsed output prefix is `results/module04_validation`; its uncollapsed output prefix is `results/module06_validation`. The table definitions below apply to both and to gene-specific validation prefixes in Module 7. Tutorial outputs use the same basenames under results/tutorial/. The `.validation.rds` file stores validation evidence, distinct from the fitter's `.models.rds` pilot.


Reviewed collapsed results selected Clone 3-low and Clone 0-high in 100/100 successful fits; this describes the chosen resampling scheme, not 100 independent tumors. The same validator also handles Module 6 when supplied its pilot. Working AIC/BIC do not repair dependent observations or topology uncertainty.

### module04_validation.stability.tsv

**One row:** One method-specific coefficient/contrast across resamples. Updated validator adds overlap columns; old approved collapsed tables need not contain them.

| Column | Meaning and interpretation |
|---|---|

| `term` | Regression term/branch ID, or a contrast identifier in resampling summaries. Interpret together with model and effect_type, not by ID alone. |
| `full_value` | Coefficient/contrast from the full-data pilot. It is not the subsample mean. |
| `effect_type` | Distinguishes penalized branch coefficient, linear basis coefficient, equal-clone contrast, and within-clone cell contrast. |
| `label` | Readable term/contrast label, including clone/group context where applicable. |
| `attempted` | Number of requested subsamples, including failed or non-estimable cases. |
| `successful` | Number of finite estimates available for this specific term; the frequency denominator. |
| `failed` | Number of method-level computational failures. Inspect iteration_status for reasons. |
| `not_estimable` | Attempts without an identifiable/adequately supported estimate. For uncollapsed contrasts, includes term-specific loss of minimum group size even if other contrasts succeeded. |

| `q95` | 95th percentile under the same rule; NOT a confidence bound. |
| `overlap_neighborhood_frequency` | Uncollapsed EN only: fraction of successful fits selecting this branch OR a branch with descendant-cell Jaccard overlap >=0.8. Not a disjoint region probability or historical support. |

| Column | Meaning and interpretation |

| `delta_BIC` | BIC minus the minimum valid BIC in the same comparison. |
| `equivalence_group` | Refits spanning the same prediction space share this label. Their likelihood cannot determine a unique historical branch explanation. |

## Module 6: exploratory cellular-branch analysis

Use actual within-clone cells for the contrast, not global clone-versus-rest DEG values. A stable expression subdivision can reflect cell state or environment without validating ancestry. Sister-cell comparisons are conditional on the supplied uncertain tree. Validation outputs use the Module 5 table definitions, with prefix module06_validation. The CLDN16 the example below explains the results without treating them as expectations for other genes or datasets.


### CLDN16 example: what the results mean

The run used 1,512 cells across four clones and 109 eligible branch predictors.

| Result | Observed value | How to read it |
|---|---|---|
| Full-fit Elastic Net selection | 11 branches: two whole-clone partitions and nine within-clone splits | Several nested edges can distribute one expression pattern across coefficients. Eleven selected edges do not establish eleven historical expression shifts. |
| Elastic Net resampling | 100/100 successful fits; eight full-fit branches selected in 100%, others in 96%, 92%, and 32% | Some exact branches recur much more consistently than others when cells are subsampled on this fixed tree. These frequencies are not probabilities that an ancestral shift occurred. |
| Signs among nonzero estimates | Consistent for all 11 full-fit selected branches | The estimated direction is consistent when the branch is selected; a rarely selected branch can still have consistent conditional signs. |
| Full linear resampling | 91 successful; nine non-estimable | Some subsamples lose the independent predictor information needed to estimate the saved basis. These nine cases are unavailable estimates, not zero effects. |
| Contrast availability | 187 ready; 21 with insufficient cells; 664 with no within-clone split | An unavailable contrast does not show absence of a biological effect. It means that the requested comparison cannot be estimated under its group rules. |
| Contrast resampling | Method completed all 100 iterations; individual contrasts had 10–100 usable estimates | Read each contrast's `successful` and `not_estimable` counts. Completion of the contrast method does not mean every contrast was supported in every iteration. |

These colors show fitted contributions, not branch support or proven ancestral events.

**Does the extra cellular detail improve the analysis?** In `module06.fit_metrics.tsv`, clone-balanced training R-squared is 0.8679 for clone means, 0.8621 for Elastic Net, and 0.8758 for the full linear model. The uncollapsed linear model improves apparent R-squared by about 0.0079 over clone means, using substantially more independent predictor directions. Elastic Net's shrinkage can make its training fit worse than the unshrunk clone reference. These are training comparisons, not independent predictive validation.

In `module06_validation.model_comparison.tsv`, the clone-mean model has the lowest BIC among the 135 evaluated working models: 2564.144. The next distinct prediction space is 27.832 BIC units higher. Under this particular independent, equal-variance Gaussian cell-error assumption, BIC favors the simpler clone-level description. The displayed next model has a lower AIC than clone means (2528.121 versus 2537.538), illustrating that the criteria penalize complexity differently. The search was bounded, so this is not an exhaustive optimum over all branch subsets. Neither criterion resolves cell dependence, confounding, or uncertain within-clone topology.

**Practical conclusion:** retain the collapsed analysis as primary and the uncollapsed analysis as exploratory. Several within-clone expression subdivisions are reproducible under cell subsampling, but their ancestry remains unverified. These results for suggest Module 6 is technically ready for the small Module 7 gene panel; this does not justify larger batches or stronger biological claims automatically. The later integrated report should reproduce these interpretations from the actual run's tables rather than hard-code this example.

### How the default five-gene test panel is selected

`--genes` and `--gene_list` are optional. If neither is given, script 07 selects distinct genes in this order from the finite, variable rows of `module03.expression.rds`:

| Step | Rule | Current prepared-data selection |
|---|---|---|
| 1 | Use CLDN16 when prepared; otherwise the first available usable gene. | CLDN16 — previously tested pilot anchor. |
| 2 | Largest range between clone means among remaining genes. | S100A10 — strong clone differences. |
| 3 | Lowest nonzero expression fraction among remaining genes. | PAMR1 — sparse detection. |
| 4 | Highest nonzero expression fraction among remaining genes. | S100A4 — broad detection. |
| 5 | Smallest range between clone means among remaining genes. | LINC03061 — smaller clone differences within this prepared candidate set. |

Each chosen gene is removed from consideration for later steps. Ties in steps 2–5 are ordered by gene identifier using the current R session's character ordering. Fewer than five usable genes produces a smaller panel. Selection is relative to the prepared genes, not all genes in the Seurat object; other datasets can select different genes. This is a descriptive test of different patterns, not a guarantee of biological diversity or an independent negative-control experiment.

Every listed gene must already be finite and variable in the Module 3 prepared expression; missing/unsupported genes are reported before fitting. `selection_reason` then reads `user-specified prepared gene` instead of an automatic rule. ### Numerical sign summaries near zero
